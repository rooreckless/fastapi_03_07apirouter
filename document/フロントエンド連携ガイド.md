# フロントエンド連携ガイド

## 概要
このFastAPIプロジェクトは、Vue.jsフロントエンドからのアクセスをサポートするCORS設定を含んでいます。

## 開発環境での使用方法

### 1. FastAPIバックエンドの起動
```bash
cd fastapi_03_07apirouter
docker compose up
```

### 2. Vueフロントエンドの起動（別ターミナル）
```bash
cd ../fastapi_frontend
docker compose up
# または
npm run dev
```

### 3. CORS動作確認
以下のエンドポイントでCORS設定を確認できます：
- `GET http://localhost:8000/cors-test`

### 4. コマンドでの動作確認

```bash
curl -H "Origin: http://localhost:3000" -H "Access-Control-Request-Method: GET" -H "Access-Control-Request-Headers: X-Requested-With" -X OPTIONS http://localhost:8000/cors-test
```

```bash

curl -H "Origin: http://localhost:3000" http://localhost:8000/cors-test
# レスポンスヘッダーを含めて
curl -v -H "Origin: http://localhost:3000" http://localhost:8000/cors-test
```

## 本番環境での展開

### AWS ECS Fargate + CloudFront構成

#### 1. ECS Fargateでのバックエンド展開
```bash
# 本番用Docker Composeファイルを使用
docker compose -f docker-compose.prod.yml up
```

#### 2. CloudFront設定
1. `.envs/production/cors`ファイルを編集
2. CloudFrontディストリビューションのドメインを設定
```bash
CORS_ORIGINS=https://your-cloudfront-domain.cloudfront.net,https://your-custom-domain.com
```

#### 3. ECSタスク定義での環境変数
ECSタスク定義で以下の環境変数を設定：
```json
{
  "environment": [
    {
      "name": "CORS_ORIGINS",
      "value": "https://your-cloudfront-domain.cloudfront.net"
    },
    {
      "name": "CORS_CREDENTIALS",
      "value": "true"
    },
    {
      "name": "CORS_METHODS", 
      "value": "GET,POST,PUT,DELETE,OPTIONS,PATCH"
    },
    {
      "name": "CORS_HEADERS",
      "value": "*"
    }
  ]
}
```

## APIエンドポイント一覧

### 認証
- `POST /auth/token` - JWT トークン取得
- `POST /auth/register` - ユーザー登録

### カテゴリ管理
- `GET /categories/` - カテゴリ一覧取得
- `POST /categories/` - カテゴリ作成
- `GET /categories/{id}` - カテゴリ詳細取得
- `PUT /categories/{id}` - カテゴリ更新
- `DELETE /categories/{id}` - カテゴリ削除

- `GET /items/` - アイテム一覧取得
- `POST /items/` - アイテム作成
- `GET /items/{id}` - アイテム詳細取得
- `PUT /items/{id}` - アイテム更新
- `DELETE /items/{id}` - アイテム削除

### システム
- `GET /health` - ヘルスチェック
- `GET /cors-test` - CORS動作確認
- `GET /docs` - Swagger UI

## フロントエンド実装例

### Vue.js axios設定例
```javascript
import axios from 'axios'

const api = axios.create({
  baseURL: process.env.NODE_ENV === 'production' 
    ? 'https://your-ecs-alb-domain.com'
    : 'http://localhost:8000',
  withCredentials: true,
  timeout: 10000
})

// JWT トークンをヘッダーに設定
api.interceptors.request.use(config => {
  const token = localStorage.getItem('access_token')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

export default api
```

### 認証フロー例
```javascript
// ログイン
const login = async (email, password) => {
  const formData = new FormData()
  formData.append('username', email)
  formData.append('password', password)
  
  const response = await api.post('/auth/token', formData)
  localStorage.setItem('access_token', response.data.access_token)
  return response.data
}

// API呼び出し例
const getCategories = async () => {
  const response = await api.get('/categories/')
  return response.data
}
```

## トラブルシューティング

### CORS エラーが発生する場合
1. `.envs/local/cors`ファイルの`CORS_ORIGINS`にフロントエンドのURLが含まれているか確認
2. フロントエンドのポート番号が正しいか確認（3000, 8080, 5173等）
3. Docker Composeを再起動してCORS設定を反映

### 認証エラーが発生する場合
1. JWTトークンが正しくヘッダーに設定されているか確認
2. トークンの有効期限が切れていないか確認
3. `withCredentials: true`が設定されているか確認

## セキュリティ考慮事項

### 本番環境
- CORS_ORIGINSを特定のドメインに限定
- HTTPS通信を必須とする
- セキュリティヘッダーの追加を検討

### 開発環境
- 開発用のCORS設定は緩く設定済み
- 本番環境では必ず適切に制限すること
